# Copper Golem UI

A full UI theme for ROSE Online, made for [ROSE Mod Launcher](https://github.com/Zurnny/Rose_Mod_Launcher). It is the [Steampunk UI](https://github.com/Zurnny/SteamPunk) recoloured after the copper golem:

- copper plates and trims (Steampunk's brass)
- cool gunmetal panels (Steampunk's dark iron)
- purple highlights for selected tabs and buttons, like the golem's banners
- gold scrollbars

Everything Steampunk has is included (porthole minimap, HUD trackers, DPS meter, chat colours, item mall wishlist, element chart and the rest), plus copper cursors and a matching launcher skin.

## Install
1. Download this repo (Code > Download ZIP) and open it.
2. Copy the **Copper Golem UI** folder into `Launcher Mods` in your ROSE Online folder.
3. In the launcher pick **Copper Golem UI** under UI Theme and restart the game.

It is a UI Theme, so it replaces Steampunk while it is on (only one theme at a time). It updates itself from this repo whenever the launcher opens.

`build_copper.py` is the script that makes it from the Steampunk files.
